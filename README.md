# \# Mon CV HTML et CSS

# 

# \## Présentation

# 

# Ce projet consiste à créer un CV sous forme de page web en utilisant HTML et CSS.

# 

# Le CV présente le profil, les compétences, les expériences professionnelles et les formations.

# 

# \## Technologies utilisées

# 

# \- HTML5

# \- CSS3

# 

# \## Structure du projet

# 

# ```text

# Mon\_CV\_HTML\_CSS/

# │

# ├── index.html

# ├── README.md

# │

# ├── css/

# │   └── style.css

# │

# └── images/

# &#x20;   ├── profil.jpg

# &#x20;   ├── github.svg

# &#x20;   ├── linkedin.svg

# &#x20;   └── instagram.svg

# ```

# 

# \## Fonctionnalités

# 

# \- Présentation du profil

# \- Affichage des formations et expériences

# \- Présentation des compétences et des langues

# \- Intégration d'une photo et d'icônes

# \- Adaptation de l'affichage aux ordinateurs et aux téléphones

#
